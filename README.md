\# Sentinel — Real-Time Website \& API Monitoring Platform



Sentinel is a real-time monitoring platform for tracking the uptime, health, and latency of websites and APIs.



\## Tech Stack

\* \*\*Backend:\*\* Python, FastAPI, SQLAlchemy, PostgreSQL

\* \*\*Frontend:\*\* Next.js, TypeScript, Tailwind CSS

\* \*\*Monitoring:\*\* HTTPX + Async Scheduler

\* \*\*DevOps:\*\* Docker, Docker Compose, GitHub Actions (CI/CD)
